# 价格与数量使用 decimal128(38, 18)，不使用 float64

所有价格、数量、金额字段在 Arrow schema、Parquet、IPC 与回放中统一为 `decimal128(38, 18)`，JSON 中序列化为字符串，CSV 输出十进制原文，任何路径都不得经过浮点转换。理由：行情网关的输出会被用于回测与对账，float64 的二进制舍入会在跨源比较、累计成交量与最小价位判断中制造不可解释的偏差；现货加期货共用一套 schema 时，精度不能依赖数据源恰好是"加密现货"这一临时事实。代价是 pandas 侧只能得到 `object`/`Decimal`，聚合与统计变慢。
